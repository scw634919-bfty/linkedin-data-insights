# LinkedIn Data Insights

Small data analysis projects using SQL and Python.

| Project | Question | Tools |
|---|---|---|
| [E-commerce Negative Margin](day1_ecommerce_margin/) | Which SKUs lose money, and why? | SQL (DuckDB), pandas, matplotlib |

## How to run

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Then open the notebook in each project folder.
